# Project Documentation and Limitations

## Project overview

This is an educational mini-project about bacterial antimicrobial resistance, using *Escherichia coli* and ciprofloxacin as its example. It combines explanatory material, embedded charts, and a browser-based demonstration.

## Data provenance

The current website contains summary figures for 10 example isolates (30% susceptible, 20% intermediate, and 50% resistant). The repository does not currently document a dataset accession, sample-level data file, retrieval date, or reproducible analysis that independently verifies those figures.

Before presenting these values as research findings:
- Identify and cite the exact dataset or publication.
- Record stable accessions/identifiers and the date the data were retrieved.
- Document how observations were selected and excluded.
- Provide the analysis steps needed to reproduce the summary figures.
- Label any illustrative or synthetic values clearly as examples.

Do not describe example figures as measured findings until their provenance is verified.

## Educational and clinical limitations

This project is for learning and demonstration only. It is not a diagnostic system or clinical decision-support tool. The simplified example thresholds and output logic have not been validated for patient care and must not be used to choose, change, or dose antibiotics. Real laboratory results require interpretation by qualified professionals using current, organism- and method-specific standards.

## Website quality checklist

- Keep the page usable on narrow mobile screens; do not hide navigation links without providing an accessible alternative.
- Provide a keyboard-accessible “Skip to main content” link.
- Ensure all interactive controls have visible keyboard focus and sufficiently large touch targets.
- Announce dynamically updated demo output to assistive technology (for example, with an appropriate live region).
- Respect reduced-motion preferences.
- Give charts meaningful alternative text and nearby text summaries.
- Keep the educational limitation visible near the interactive demonstration.
- Separate source data, analysis, and presentation so results can be reproduced and reviewed.

## Scope of this documentation

This document records reproducibility, accessibility, and educational-scope improvements. It does not validate or change the demo's scientific thresholds or classification logic.
