# Bacterial Drug Resistance — Educational Mini-Project

## Overview
This repository contains a browser-based educational mini-project about antimicrobial resistance, using *Escherichia coli* and ciprofloxacin as an example. It includes explanatory content, charts, and an interactive demonstration.

**Important:** This is a learning demonstration, not a validated diagnostic system or clinical decision-support tool. Do not use it to choose, change, or dose antibiotics.

## Live website
https://karna508.github.io/index.html/

## Repository contents
- `index.html` — website interface and browser-based demonstration.
- `PROJECT_DOCUMENTATION.md` — project scope, known data-provenance gaps, and accessibility notes.
- `DATASET_PROVENANCE_TEMPLATE.md` — template for recording the source and verification steps for any dataset used.

## Data and reproducibility status
The repository's displayed example summary has not yet been independently verified against a documented NCBI accession and retained source file. Until that verification is complete, do not describe the displayed percentages as confirmed NCBI-derived findings.

To complete the data record:
1. Record the exact NCBI resource and accession or project/sample identifiers.
2. Keep the original downloaded file and note its filename, format, and download date.
3. Document the fields used and any filtering or exclusions.
4. Record the script or notebook used to calculate each displayed statistic.
5. Recalculate the summary from the source data and check that the website matches it.
6. Complete `DATASET_PROVENANCE_TEMPLATE.md` without guessing missing information.

## Accessibility and quality
The website includes keyboard-focus styling, a skip link, reduced-motion support, and an educational-use notice. Test navigation, keyboard access, small-screen layout, and dynamic result announcements before presenting the project.

## Limitations
- The example is educational only and is not validated for clinical use.
- Displayed figures remain unverified until their source and calculations are documented.
- A source citation alone does not establish that a statistic was calculated correctly.
- This README does not claim that the demonstration is a validated machine-learning model.
